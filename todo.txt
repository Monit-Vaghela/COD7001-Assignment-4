Facts to be mentions
----------------------------------------
1. Bytecode is assumed to be valid (i.e no issue with bytecode)
2. CMP uses a-b logic, i.e
| Expression | Result   | JZ      | JNZ     |
| ---------- | -------- | ------- | ------- |
| `a == b`   | `0`      | jump    | no jump |
| `a != b`   | non-zero | no jump | jump    |
| `a < b`    | negative | no jump | jump    |
| `a > b`    | positive | no jump | jump    |

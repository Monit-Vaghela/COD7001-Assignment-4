Facts to be mentions
----------------------------------------
1. Bytecode is assumed to be valid (i.e no issue with bytecode)
2. CMP uses a-b logic, i.e
| Expression | Result   | JZ      | JNZ     |
| ---------- | -------- | ------- | ------- |
| `a == b`   | `0`      | jump    | no jump |
| `a != b`   | non-zero | no jump | jump    |
| `a < b`    | negative | no jump | jump    |
| `a > b`    | positive | no jump | jump    |

3. Opcode lengths
| Instruction | Bytes |
| ----------- | ----- |
| PUSH val    | 2     |
| JMP addr    | 2     |
| JZ / JNZ    | 2     |
| STORE idx   | 2     |
| LOAD idx    | 2     |
| CALL addr   | 2     |
| Others      | 1     |

4. Talk about Error message format.
5. the arguments
    * -a : means only assemble, input : .asm, output: .bin
    * -e : means only execure, input: .bin output: Execution
    * -ae : Streamline assemble and Execution
    * -d : print Debugging info.
